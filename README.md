# Cashflow Gate Trading V1

Independent, mobile-first dark trading interface prototype for market education, virtual practice trading, and skill-based youth challenges.

## Included
- Responsive dark UI with green/red market movement styling.
- Illustrative commodity, crypto and forex watchlist with filters.
- CFG practice demo balance, simulated buy/close flows, positions and demo P/L.
- Youth market-direction prediction challenge and XP counter.
- No wagers or real-money prize mechanics.

## Run
Open `index.html` in a browser or deploy as a static site through Vercel.

## Important limits
All prices, balances, XP and leaderboard values are demo data. The practice balance is denominated in CFG and is labelled Practice Funds Only; it is not real CFG, has no monetary value, and is isolated from the real CFG wallet, Treasury and financial ledger. They are not current market quotes. Browser state is device-local and can be reset and is not suitable for real financial records. There is no live market feed, authentication, server-side ledger, broker connection, payment integration or real trading execution.

## Roadmap
1. Review mobile UI and accessibility.
2. Add secure backend authentication and server-side simulation ledger.
3. Integrate a licensed market-data source with timestamps and stale-data handling.
4. Add persistent challenges, audited scoring and anti-fraud checks.
5. Review applicable licensing, age and consumer-protection requirements before real-money trading, investment participation or cash rewards.

Cashflow Gate remains standalone. Any Maharoos entry point should be a link or separately designed identity flow; financial ledgers and business logic must not be merged.
